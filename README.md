**Marisol Vice** — an original 2D top-down open-world crime game that runs entirely in the browser, no build step and no network needed. Explore the invented island city of Port Marisol on foot and by car: steal and drive any car, dodge or fight the police across a 0–5 star wanted system, and work through a 4-mission story chain for cantina owner Rosa Delgado — then keep earning with free-roam courier jobs. Features a live minimap HUD, traffic and pedestrian AI, WebAudio-synthesized sound, and localStorage saves. Every name, character, vehicle, place, piece of art and line of code in this game is original work created for this entry.

## Run it

```sh
python3 -m http.server 8000 -d game
# then open http://localhost:8000 in desktop Chrome
```

Controls: WASD / arrows to move, Shift to sprint, F to enter or exit a car, mouse to aim, click to shoot, Esc to pause.
